# LeRobot × LeIsaac

[![LeRobot](https://img.shields.io/badge/LeRobot-HuggingFace-FFD21E?logo=github&logoColor=black)](https://github.com/huggingface/lerobot)
[![LeIsaac](https://img.shields.io/badge/LeIsaac-LightwheelAI-4A90D9?logo=github&logoColor=white)](https://github.com/LightwheelAI/leisaac)

Monorepo combining [LeRobot](https://github.com/huggingface/lerobot) and [LeIsaac](https://github.com/LightwheelAI/leisaac) for training and evaluating robot manipulation policies in Isaac Sim, with the goal of sim-to-real transfer on a custom 6-DOF arm.
